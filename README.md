- 테마 색상 변경이 Windows WebView 편집기의 커서·선택·거터·스크롤바에 즉시 반영됩니다.
- 설정에서 운영체제 기본 맞춤법 검사를 켜거나 끌 수 있습니다.
- 빌드·GitHub Release 업로드·릴리즈 README 갱신을 한 명령으로 수행하는 자동화를 추가했습니다.
